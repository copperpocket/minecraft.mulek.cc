# Minecraft Server Connection Guide

Static instructions page for connecting to our Minecraft server, hosted at
[minecraft.mulek.cc](https://minecraft.mulek.cc).

## Structure

- `index.html` — the instructions page
- `nginx.conf` — nginx config for serving the static page
- `Dockerfile` — builds the container deployed via Dokploy

## Deployment

Deployed automatically via [Dokploy](https://dokploy.com) on push to `main`.
