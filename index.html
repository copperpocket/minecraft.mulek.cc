Quick Start

Already have Minecraft Java Edition installed?

  1. Open Minecraft → Multiplayer
  2. Add Server
  3. Server address: mc.mulek.cc
  4. Done, then double-click the server to join

Detailed Guide

1. Get Minecraft Java Edition

If you don't already own Minecraft, purchase and download the Java & Bedrock Edition bundle from the official site:

minecraft.net → Java & Bedrock Edition (PC)

Note: this server currently supports Java Edition only. Bedrock (mobile/console) is not supported.

Already own it? Install the launcher:

  1. Go to minecraft.net/download
  2. Download the Minecraft Launcher for your OS (Windows, macOS, or Linux)
  3. Run the installer and sign in with your Microsoft account

2. Launch the correct version

This server runs version 26.2. If your launcher opens a different version by default:

  1. In the Minecraft Launcher, click the dropdown next to the Play button
  2. Select Installations → New Installation
  3. Choose version 26.2 from the version list, name it, and create it
  4. Select that installation before clicking Play

Mismatched versions are the most common reason people can't connect.

3. Add the server

  1. From the main menu, click Multiplayer
  2. Click Add Server
  3. Server Name: anything you like, or leave it blank
  4. Server Address: mc.mulek.cc
  5. Click Done
  6. Double-click the server entry in your list to join

Troubleshooting

  • "Can't connect to server" — double check the address is exactly mc.mulek.cc with no extra spaces
  • "Outdated server/client" — your Minecraft version doesn't match; see step 2 above
  • Connects but times out or hangs — server may be restarting, wait a minute and try again
